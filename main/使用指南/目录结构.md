# 目录与文件规则

## 版本目录

内容分支根下每个一级目录是一个**版本**：

```text
data/
├── config.js
├── main/            # → /docs-zh-CN/main
│   └── ...
└── 1.3.4/           # → /docs/1.3.4（若存在）
```

版本是否展示、显示成什么名字，由 `config.js` 决定：

```js
document: {
  default_branch: "main",
  available_branches: [
    { name: "main", label: "v2.0.2" },
    { name: "1.3.4", label: "v1.3.4" }
  ]
}
```

- `available_branches` 里列出但目录不存在的版本会被自动隐藏
- 目录存在但没在 `available_branches` 里列出，会被追加到列表末尾
- `default_branch` 指向的版本是站点默认版本

## 索引页与可点击性

`document.index_pages` 定义索引页文件名，默认：

```js
index_pages: ["README.md", "README.html", "index.md", "index.html"]
```

规则：

| 情况 | 侧栏表现 | URL |
| --- | --- | --- |
| 目录含索引页 | 可点击，进入索引文档 | `/docs-zh-CN/main/使用指南` |
| 目录不含索引页 | **不可点击**，仅可展开/折叠 | —— |
| 目录只有 `README.md` | 可点击，**不显示展开/折叠按钮** | `/docs-zh-CN/main/使用指南` |
| 普通文件 | 可点击 | `/docs-zh-CN/main/使用指南/目录结构` |

> [IMPORTANT] 侧栏不会生成指向 404 的链接。目录要可点，就给它放一个 `README.md`。

## URL 规则

| 内容路径（分支内） | URL |
| --- | --- |
| `main/README.md` | `/docs-zh-CN/main` |
| `main/使用指南/README.md` | `/docs-zh-CN/main/使用指南` |
| `main/使用指南/目录结构.md` | `/docs-zh-CN/main/使用指南/目录结构` |
| `main/示例.html` | `/docs-zh-CN/main/示例` |

- 扩展名不出现在 URL 中
- 索引页会被折叠成所在目录
- URL 使用真实路径（没有 `#`），可以直接分享、刷新、被搜索引擎收录

### 多语言文档的 URL

`/docs-{语言}/` 中的语言是**文档语言**；站点界面语言只保存在浏览器 `localStorage`，不出现在 URL 中。

| 内容路径 | URL |
| --- | --- |
| `main/使用指南/README.md`（中文） | `/docs-zh-CN/main/使用指南` |
| `main/en/使用指南/README.md`（英文） | `/docs-en/main/使用指南` |
| `main/使用指南/README.en.md`（英文） | `/docs-en/main/使用指南` |

- 切换站点语言时，文档语言会自动跟随（站点语言本身只影响界面文案与切换器状态）
- 也可以只切换文档语言，站点界面语言保持不变
- 目标语言没有译文时显示默认语言内容并给出提示
- 旧地址 `/docs/main/...` 会自动跳转到 `/docs-{默认文档语言}/main/...`

## 目录配置与排序（path.json）

默认顺序是「先文件、后子目录，各自按标题的本地化顺序排序」。
要自定义**显示名**与**顺序**，在内容根或版本目录下放一个 `path.json`：

```json
{
  "title": "首页",
  "translations": {
    "en": { "title": "Home" }
  },
  "children": [
    {
      "path": "README.md",
      "title": "概览",
      "icon": "home",
      "translations": {
        "en": { "title": "Overview", "icon": "home" }
      }
    },
    {
      "path": "使用指南",
      "title": "使用指南",
      "icon": "book",
      "translations": {
        "en": { "title": "User Guide", "icon": "book-open" }
      }
    }
  ]
}
```

- **数组顺序即展示顺序**；没写进 `path.json` 的条目排在后面
- `title` 只影响显示名，**不改变文件名与 URL**
- `icon` 支持图标库 id 或图标链接（目录与文档都可以设置）
- `translations[语言]` 可覆盖 `title`、`icon`、`hidden`，以及索引页的 `index.title` / `index.icon`
- `path` 可以指向目录（`使用指南`）或文件（`使用指南/目录结构.md`）
- `hidden: true` 让条目在侧栏隐藏（文件仍可直链访问）

> [TIP] 在文档页侧栏**拖拽**条目即可排序，**双击**条目即可改名，右键可设置图标；
> 也可以在控制台「目录与排序」里拖动、点击上移 / 下移，或拖入 / 拖出文件夹。
> 跨文件夹移动会真实移动内容文件，并进入待提交列表。

读取位置与优先级：

| 位置 | 作用范围 |
| --- | --- |
| `{内容根}/path.json` | 所有版本 |
| `{内容根}/{版本}/path.json` | 仅该版本（覆盖根配置） |

legacy 的嵌套写法（`children` 里再放 `children`）同样可用，旧 `path.json` 可以直接搬过来。

## 多语言文档

`i18n` 配置支持两种组织方式（可混用）：

```text
# 语言文件夹
main/zh/使用指南/README.md
main/en/使用指南/README.md

# 文件二级后缀
main/使用指南/README.zh.md
main/使用指南/README.en.md
```

- 没有语言标记的文件属于默认语言
- 语言文件夹名取 `document_languages[].dir`，文件后缀取 `document_languages[].suffix`
- 语言文件夹下的 `path.json` 可以单独覆盖该语言的显示名与排序
- 同一语言内优先使用显式标记的文件

## 支持的文件类型

```js
supported_extensions: [".md", ".html"]
```

- `.md` / `.markdown`：走 Markdown 渲染管线
- `.html`：独立 `iframe` 呈现，脚本、样式、iframe 等原样执行
  （`extensions.html_scripts: false` 可关闭脚本）

## 标题来源

文档在侧栏与搜索结果里的标题，按以下顺序取：

1. 第一个 `# ` 一级标题
2. 第一个 `## ` 二级标题
3. 文件名（下划线换成空格）

目录的标题取它的索引页标题；`path.json` 里的 `title` 优先级最高。

## 新增版本

```bash
# 在内容分支上直接建目录即可
mkdir -p data/1.3.4 && echo "# v1.3.4" > data/1.3.4/README.md
```

然后在 `config.js` 的 `available_branches` 里加一行，重新构建。

## 相对路径与目录穿越

内容源做了路径校验：

- 一律使用 `/` 分隔（Windows 反斜杠会自动转换）
- 不允许 `..` 越出内容根
- 编辑器新建文档时会校验扩展名是否在 `supported_extensions` 内

## 外部文档挂载

在 `path.json` 里给一个目录加 `external`，就能把别的仓库/公开目录当成侧栏的一部分：

```json
{
  "children": [
    {
      "path": "外部文档",
      "title": "插件开发",
      "external": {
        "mode": "github_tree",
        "url": "https://github.com/owner/repo/tree/main/docs"
      }
    }
  ]
}
```

```json
{
  "path": "外部文档",
  "external": {
    "mode": "path_json",
    "url": "https://example.com/docs/path.json"
  }
}
```

- `github_tree`：GitHub 目录链接，走**无需 token** 的 Contents API
- `path_json`：一个 `path.json` 地址，或一个**包含 path.json 的公开目录**
- 构建期会拉取一次并参与预渲染；前端也会实时刷新（`document.runtime_fetch`）
- 挂载失败只在构建日志里给出 warning，不影响其余页面
