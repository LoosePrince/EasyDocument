## 一句话版本

- 每篇文档是一个 `.md` 或 `.html` 文件，放在版本目录下
- 目录里有 `README.md` 才可点击，否则只作分组
- 文档之间优先用相对路径链接，系统会自动改写成真实 URL
- 保存 ≠ 提交 ≠ 重建，三者语义不同（见 [编辑与发布](../编辑与发布/README.md)）
