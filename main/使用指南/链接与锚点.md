# 文档链接的写法

## 推荐：相对路径

```md
[目录结构](./目录结构.md)
[回上一级](../README.md)
[另一篇文档](./另一篇.md#小节标题)
```

系统在渲染时会把相对路径改写成真实 URL：

| 写法 | 位置 | 结果 |
| --- | --- | --- |
| `./目录结构.md` | `使用指南/README.md` | `/docs-zh-CN/main/使用指南/目录结构` |
| `../README.md` | `使用指南/目录结构.md` | `/docs-zh-CN/main` |
| `./README.md` | `使用指南/目录结构.md` | `/docs-zh-CN/main/使用指南` |

> [TIP] 优先写相对路径：以后调整目录结构或复制文档，链接依然有效。

## 绝对路径

以 `/` 开头时按站点根解析：

```md
[配置详解](/docs-zh-CN/main/配置详解)
[配置详解](/docs-zh-CN/main/配置详解/站点信息)
```

也兼容旧版的 `/data/main/xxx` 写法（会自动去掉 `data/` 前缀）。

## 锚点

```md
[跳到「排序规则」](./目录结构.md#排序规则)
[本页锚点](#URL规则)
```

标题锚点 id 由标题文本生成，中文保持原样（URL 中会被百分号编码）。
重复标题会自动去重：第二个同名标题的 id 为 `标题-1`。

## 外链

```md
[GitHub](https://github.com/LoosePrince/EasyDocument)
```

外链会自动加上 `target="_blank"` 与 `rel="noopener noreferrer"`。

## 图片

```md
![示意图](./assets/diagram.png)
```

- 图片会加上 `loading="lazy"`，点击可放大（灯箱：缩放 / 旋转 / 拖拽 / 下载）
- 图片同样支持相对路径

## 顶部导航里的链接

`config.js` 的 `navigation.nav_links`：

```js
nav_links: [
  { text: "首页", url: "/" },
  { text: "文档", url: "/docs-zh-CN/main" },
  {
    text: "教程",
    url: [
      { text: "快速入门", url: "/docs-zh-CN/main/快速入门", icon: "fas fa-rocket" },
      { text: "使用指南", url: "/docs-zh-CN/main/使用指南", icon: "fas fa-book" }
    ],
    icon: "fas fa-graduation-cap"
  },
  { text: "GitHub", url: "https://github.com/…", external: true }
]
```

- `url` 为数组时渲染成下拉菜单
- 站内路径会校验是否存在：**目标页面不存在时该链接不可点击**（灰色、`aria-disabled`），不会跳到 404
- 旧版写法 `main/`、`main/#路径/` 仍会被自动转换

## 首页里的链接

`home.hero.button_link`、`home.quick_links[].url`、`home.get_started.button_link` 同样支持站内路径与旧版写法，并且会被解析为真实地址。

## 文档底部信息

`extensions.github.edit_link` 为 true 时，文档底部会出现「在 GitHub 上编辑」，链接指向内容分支对应文件：

```text
https://github.com/{owner}/{repo}/edit/{内容分支}/{分支内路径}
```

`extensions.git` 控制最后编辑时间与贡献者展示（需要构建期拿到 git 信息，缺失时自动隐藏）。
