# 搜索与主题

## 搜索

搜索索引在**构建期**生成，随站点一起发布：

- 每个版本一份索引，文件为 `search-index.<版本>.json`
- 索引内容：标题、正文（去 Markdown 标记、截断 1000 字符）、关键词
- 运行时用 MiniSearch 建索引，中文按**二元组**切分，支持前缀与模糊匹配

### 打开方式

| 方式 | 说明 |
| --- | --- |
| 顶栏搜索框 | 点击任意位置的搜索按钮 |
| 首屏搜索框 | 首页 Hero 区（`home.hero.search_placeholder` 非空时） |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> | 任意页面 |

### 结果面板

- 多版本时可切换搜索范围（默认版本）
- 外部文档在构建期成功拉取正文后也会进入索引；结果上会标注语言
- <kbd>↑</kbd> <kbd>↓</kbd> 选择，<kbd>Enter</kbd> 打开，<kbd>Esc</kbd> 关闭
- 命中片段居中截取，显示前后各 60 字符

### 配置

```js
search: {
  enable: true,        // 关闭后顶栏与首屏搜索框都隐藏
  min_chars: 2,        // 少于该字符数不搜索
  max_results: 20,     // 最多返回条数
  placeholder: "搜索文档…",
  search_drafts: true,  // 同时搜索浏览器内的本地草稿
  search_on_type: true,// 输入即搜（否则需回车）
  match_distance: 50   // 片段内多次命中的最小间隔
}
```

## 暗色模式

优先级：**用户手动选择** > `appearance.default_dark_mode` > 系统偏好。

```js
appearance: {
  default_dark_mode: "auto" // "auto" | "light" | "dark"
}
```

- 手动选择记录在 `localStorage["easydocument:theme"]`
- 首屏通过内联脚本在样式加载前应用，避免闪烁
- 未手动选择时，跟随系统 `prefers-color-scheme` 变化

## 主题色

```js
appearance: { theme_color: "#3b82f6" }
```

主题色会生成 CSS 变量 `--ed-primary`、`--ed-primary-rgb`、`--ed-primary-soft`，
作用于链接、按钮、目录高亮、进度条等。

## 字体

```js
appearance: { font_family: "" }
```

- 留空：使用内置 **Outfit Variable**（可变字重）
- 非空：覆盖 `--ed-font-family`，例如 `"Inter, system-ui, sans-serif"`

## 代码高亮主题

```js
document: {
  code_block: {
    theme: { light: "github", dark: "github-dark" }
  }
}
```

- 亮/暗各一个主题，切换暗色模式时自动切换
- `github` 是别名，内部归一为 `github-light`
- 主题名用 shiki 内置名称，例如 `one-dark-pro`、`vitesse-light`

## 阅读辅助

| 配置 | 效果 |
| --- | --- |
| `extensions.progress_bar.enable` | 顶部阅读进度条 |
| `navigation.back_to_top` | 右下角返回顶部 |
| `navigation.prev_next_buttons` | 底部上一篇 / 下一篇 |
| `navigation.breadcrumb` | 面包屑（无索引页的目录项不可点） |
| `document.toc_depth` | 右侧目录显示到几级标题 |
| `document.toc_numbering` | 目录显示编号 |
| `document.toc_ignore_h1` | 编号时忽略一级标题 |
| `document.toc_dynamic_expand` | 超出深度的标题在激活时展开 |

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| <kbd>E</kbd> | 进入 / 退出编辑模式（焦点不在输入框时） |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>S</kbd> | 在编辑器中保存到本地草稿 |
| <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd> | 打开搜索 |
| <kbd>Esc</kbd> | 关闭搜索 / 菜单 / 大图 |
