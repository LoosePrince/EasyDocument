# 已知限制

2.0.0 是重写版本，以下行为是有意为之或尚未实现，写作与配置时请留意。

## 内容模型

| 限制 | 说明 |
| --- | --- |
| 不支持手工排序 | 同一目录内固定「文件在前、目录在后」，各自按标题排序；`path.json` 的拖拽排序尚未实现 |
| 不支持外部文档挂载的完整渲染 | `document.external_docs` 配置会被解析，但挂载出的文档渲染链路尚未接线 |
| HTML 文档无站点目录 | `.html` 走沙箱 iframe，右侧 TOC 不注入，由页面自身负责 |
| HTML 文档脚本默认禁用 | 需在页面顶部点「启用脚本」 |

## 编辑

| 限制 | 说明 |
| --- | --- |
| 不提供富文本所见即所得 | 编辑始终基于 Markdown 源码，配「预览 / 分栏」；这样预览与发布结果 100% 一致 |
| 草稿不能跨设备 | 草稿存在本浏览器 `localStorage` |
| 不能只提交部分草稿 | 一键提交会推送全部草稿 |
| 删除目录只删索引页 | 目录右键「删除」删除的是该目录的索引页（如 `README.md`），不会递归删除子文件 |
| 排序不可拖拽 | 目录顺序由标题排序决定 |

## 构建与部署

| 限制 | 说明 |
| --- | --- |
| 内容分支变更不自动部署 | 需要在控制台或 `gh workflow run` 手动触发 |
| 无 SPA 回退 | GitHub Pages 不支持 rewrite，因此 `/admin` 也做预渲染；新增未预渲染的路由需同步加入 `prerender` |
| 搜索索引需重新构建 | 索引在构建期生成，新增文档后未重建则搜不到 |
| 外部资源依赖网络 | 内容源回退到 `raw.githubusercontent.com`；Mermaid 在浏览器端渲染 |

## 界面

| 限制 | 说明 |
| --- | --- |
| 图标依赖类名映射 | `nav_links[].icon` 用的是 FontAwesome 类名，内置了常用图标的 SVG 兼容映射；未覆盖的图标不会显示 |
| 缓存菜单未实现 UI | `extensions.cache_menu.enable` 已被读取，但面板尚未实现 |
| 自定义 HTML 受限 | `home.use_file`、`layout.header_file/footer_file` 注入前会消毒，脚本不会执行 |

## 兼容性

| 项目 | 说明 |
| --- | --- |
| 旧版 hash 链接 | 配置内的站内路径会自动转换；文档正文里写死的 `main/#路径` 不会 |
| 旧版 `path.json` | 不再读取；文档树由构建期扫描内容分支生成 |
| `build.py` | 不再需要，`main` 分支已移除 |

## 浏览器

支持当前主流浏览器的最新版本（Chrome / Edge / Firefox / Safari）。
不支持 IE。依赖 `structuredClone`、`ResizeObserver`、`IntersectionObserver`、`clipboard` 等现代 API。
