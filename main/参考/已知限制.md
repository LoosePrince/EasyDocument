# 已知限制

2.0.2 是重写版本，以下行为是有意为之或尚未实现，写作与配置时请留意。

## 内容模型

| 限制 | 说明 |
| --- | --- |
| 外部文档只读 | 挂载进来的文档可以浏览，但网页端编辑只写回本仓库，不能改写外部仓库 |
| 外部文档依赖网络 | 前端实时拉取需要能访问 GitHub API / 原始内容地址；离线时退化为构建期快照 |
| HTML 文档无站点目录 | `.html` 走沙箱 iframe，右侧 TOC 不注入，由页面自身负责 |
| 外部挂载搜索依赖构建期抓取 | 构建期成功拉取正文的外部文档会进入搜索索引；抓取失败的只保留标题 |

## 编辑

| 限制 | 说明 |
| --- | --- |
| 富文本层会转回 Markdown | 编辑完用 turndown 反向转换，极端嵌套结构（如表格里的提示框）可能被拍平 |
| 草稿不能跨设备 | 草稿存在本浏览器 `localStorage` |
| 不能只提交部分草稿 | 一键提交会推送全部草稿 |
| 删除目录只删索引页 | 目录右键「删除」删除的是该目录的索引页（如 `README.md`），不会递归删除子文件 |
| 侧栏拖拽不跨级 | 文档页侧栏拖拽只在同一父级内排序；跨文件夹移动请在控制台「目录与排序」里操作（会真实移动文件） |

## 构建与部署

| 限制 | 说明 |
| --- | --- |
| 内容分支变更不自动部署 | 需要在控制台或 `gh workflow run` 手动触发 |
| SPA 回退只在 404 页生效 | `404.html` 是 `index.html` 的副本，未预渲染的深链能靠它接管；但 HTTP 状态码仍是 404 |
| 搜索索引需重新构建 | 索引在构建期生成，新增文档后未重建则搜不到 |
| 外部资源依赖网络 | 内容源回退到 `raw.githubusercontent.com`；Mermaid 在浏览器端渲染 |

## 界面

| 限制 | 说明 |
| --- | --- |
| 图标使用设计 id 或链接 | `icon` 可填 `rocket` / `book` / `settings`，也可填图标链接；未知 id 回落到默认图标，旧 FontAwesome 类名仍能识别 |
| 自定义 HTML 不限制 | `home.use_file` 与 HTML 文档都原样注入/执行，请只在自己的内容分支里写可信代码 |

## 兼容性

| 项目 | 说明 |
| --- | --- |
| 旧版 hash 链接 | `/main/#/路径` 这类地址会被 `404.html` 内联脚本自动改写为新路径（在 React 水合之前完成） |
| 旧版 `path.json` | 可以原样使用：嵌套结构会被读取为「显示名 + 顺序」配置 |
| `build.py` | 不再需要，`main` 分支已移除 |

## 浏览器

支持当前主流浏览器的最新版本（Chrome / Edge / Firefox / Safari）。
不支持 IE。依赖 `structuredClone`、`ResizeObserver`、`IntersectionObserver`、`clipboard` 等现代 API。
