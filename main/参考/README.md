## 速查表

| 需求 | 写法 |
| --- | --- |
| 标题 | `# 一级` ~ `###### 六级` |
| 粗体 / 斜体 | `**粗体**` / `*斜体*` |
| 行内代码 | `` `code` `` |
| 代码块 | 三个反引号 + 语言 |
| 链接 | `[文本](./路径.md)` |
| 图片 | `![说明](./img.png)` |
| 提示框 | `> [NOTE] 标题` |
| 表格 | `\| A \| B \|` + 分隔行 |
| 任务列表 | `- [x] 完成` |
| 数学 | `$E=mc^2$` / `$$…$$` |
| 图表 | 三个反引号 + `mermaid` |
| 分隔线 | `---` |

## 排错顺序

遇到问题时按这个顺序排查，通常很快能定位：

1. **构建是否成功**：看 Actions 运行状态或本地 `npm run build` 输出
2. **内容是否进仓库**：到内容分支确认文件确实存在
3. **是否重建过**：提交后没重建，线上仍是旧版本
4. **链接目标是否存在**：站内链接指向的文档/索引页是否齐全
5. **配置是否被校验回退**：编辑台「站点配置」里的警告列表

## 关键命令

```bash
git worktree add .data origin/data   # 本地准备内容分支
npm run dev                          # 开发
npm run build                        # 构建
npm run preview                      # 以 Pages 语义预览
npm run typecheck                    # 类型检查
npm run test                         # 单元测试
npm run test:e2e                     # 端到端测试
gh workflow run deploy.yml --ref main # 手动触发部署
```
