# 图标一览

配置里的 `icon` 使用**设计图标 id**，不再依赖 FontAwesome 类名。

```js
navigation: {
  nav_links: [
    { text: "快速入门", url: "/docs/main/快速入门", icon: "rocket" }
  ]
}
```

`icon` 渲染为内联 SVG，站点**不引入任何图标字体**，因此不需要额外的 CSS 或网络请求。

## 通用

| id | 用途 |
| --- | --- |
| `rocket` | 快速开始、发布 |
| `book` / `book-open` | 文档、手册 |
| `book-marked` | 标记过的文档 |
| `guide` / `compass` | 指南、导览 |
| `graduation` / `education` / `learn` | 教程、学习 |
| `file-text` / `doc` / `docs` | 单篇文档 |
| `folder` / `tree` | 目录 |
| `link` / `anchor` | 链接、锚点 |

## 兼容旧配置

`fas fa-rocket`、`fab fa-github` 这类写法仍能识别：自动剥掉 FontAwesome 前缀后按 id 查找。
但**新配置请直接写 id**，映射表不会随时间新增。

## 未知 id

未收录的 id 会渲染为默认图标（`sparkles`），不会出现空白，也不会报错。
