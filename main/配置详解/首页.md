# 首页

首页由 `home` 配置驱动，无需写 HTML。

```js
home: {
  use_file: false,
  file_path: "/home.html",
  hero: { ... },
  sections: { ... },
  stats: [ ... ],
  features: [ ... ],
  code_demo: { ... },
  get_started: { ... },
  quick_links: [ ... ]
}
```

## 首屏 hero

```js
hero: {
  badge: "v2.0.2 · 所见即所得 · 目录配置",
  title: "EasyDocument",
  subtitle: "内容与代码分离的静态文档系统",
  description: "文档存在独立的 git 分支里…",
  logo: "/assets/img/logo.svg",
  search_placeholder: "搜索文档…",
  button_text: "开始阅读",
  button_link: "/docs-zh-CN/main",
  secondary_text: "编辑与发布",
  secondary_link: "/docs-zh-CN/main/编辑与发布"
}
```

| 字段 | 留空时 |
| --- | --- |
| `badge` | 不显示胶囊标签 |
| `title` | 使用 `site.name` |
| `subtitle` / `description` | 不显示 |
| `logo` | 不显示 Logo |
| `search_placeholder` | **隐藏首屏搜索框** |
| `button_text` | 不显示主按钮 |
| `secondary_text` | 不显示次按钮 |

> [TIP] 首屏搜索框和顶栏搜索按钮是同一个搜索面板，只是入口不同。

## 区块开关

```js
sections: {
  features:   { enable: true, title: "核心特性", description: "…" },
  docs:       { enable: true, title: "文档",     description: "…" },
  code_demo:  { enable: true, title: "同一套渲染管线", description: "…" },
  get_started:{ enable: true, title: "三步开始",  description: "…" }
}
```

首页从上到下的顺序是：Hero → 文档入口（docs）→ 特性（features）→ 代码对照（code_demo）→ 快速开始（get_started）→ 快捷入口。

不想显示某块，把 `enable` 设为 `false`。

## 亮点数字

```js
stats: [
  { value: "SSG", label: "预渲染输出" },
  { value: "真实路径", label: "无 hash 路由" }
]
```

- 显示在 Hero 下方，最多四列（窄屏两列）
- 留空数组则不显示

## 特性卡片

```js
features: [
  {
    icon: "fas fa-feather",
    title: "内容与代码分离",
    description: "文档放在独立 git 分支…"
  }
]
```

- 三列自适应网格（宽屏三列、中屏两列、窄屏一列）
- `icon` 用 FontAwesome 类名，内置图标有兼容映射

## 代码对照区

```js
code_demo: {
  filename: "README.md",
  content: "# 我的文档\n\n> [TIP] …\n"
}
```

- 左侧是源码（带文件名与窗口装饰）
- 右侧是**用同一套渲染管线**渲染的结果
- 因此这块内容可以直接展示提示框、公式、表格、代码高亮

> [NOTE] 由于在浏览器端渲染，首屏显示的是静态 HTML 之后补齐的高亮。SEO 角度它只是首页装饰，不影响文档页。

## 文档入口

「文档」区块自动生成，不需要配置内容：

- 左侧：版本卡片（版本标签、文档数量、默认标记）
- 右侧：默认版本的文档列表（最多 8 篇）

数据来自构建期扫描的内容树，所以不会出现指向不存在文档的入口。

## 快速开始

```js
get_started: {
  enable: true,
  title: "三步开始使用",
  steps: [
    { title: "把文档放进内容分支", description: "…" },
    { title: "在网页端编辑", description: "…" },
    { title: "一键提交并重建", description: "…" }
  ],
  button_text: "阅读快速入门",
  button_link: "/docs-zh-CN/main/快速入门"
}
```

## 快捷入口

```js
quick_links: [
  {
    title: "快速入门",
    description: "安装、第一篇文档、部署",
    url: "/docs-zh-CN/main/快速入门",
    icon: "fas fa-rocket"
  }
]
```

四列卡片网格。**`url` 应指向真实存在的页面**，否则点击会进入 404（这里不像顶栏导航那样自动禁用，请配置时确认目标存在）。

## 使用自定义 HTML

```js
home: { use_file: true, file_path: "/home.html" }
```

- 读取内容分支根的 `/home.html`
- 抽取 `<body>` 内部内容，移除 `<script>`、内联事件属性、`javascript:` 链接后注入
- 与下面的配置驱动区块**同时存在**：自定义 HTML 会插在 Hero 之后

> [WARNING] 消毒会移除脚本，因此自定义首页里的动画/交互脚本不会执行。需要复杂交互时建议用配置区块组合，或直接写 `.html` 文档页。
