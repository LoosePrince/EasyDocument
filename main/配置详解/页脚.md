# 页脚

```js
footer: {
  copyright: "© 2026 EasyDocument · MIT License",
  powered_by: {
    enable: true,
    text: "技术栈：",
    links: [
      { text: "React", url: "https://react.dev", external: true }
    ]
  },
  links: [
    { text: "GitHub", url: "https://github.com/…" }
  ],
  beian: {
    enable: false,
    icp: [],
    position: "bottom"
  },
  columns: [
    { key: "nav", title: "导航", type: "nav", enable: true },
    { key: "links", title: "资源", type: "links", enable: true },
    { key: "stack", title: "技术栈", type: "stack", enable: true }
  ]
}
```

## 版权

`copyright` 显示在页脚底部左侧。留空时自动使用 `© 年份 站点名称`。

## 技术栈行

```js
powered_by: {
  enable: true,
  text: "技术栈：",
  links: [{ text: "React", url: "https://react.dev", external: true }]
}
```

- 显示在底部右侧，与版权同一行
- `enable: false` 时整行隐藏

## 资源链接

```js
links: [{ text: "GitHub", url: "https://github.com/LoosePrince/EasyDocument" }]
```

出现在 `type: "links"` 的列中。

## 列

页脚中部由 `columns` 驱动：

| type | 内容来源 |
| --- | --- |
| `nav` | `navigation.nav_links` 中的一级链接（不含下拉） |
| `links` | `footer.links` |
| `stack` | `footer.powered_by.links` |

- `enable: false` 隐藏该列
- 列顺序即数组顺序
- 最多四列自适应（宽屏），窄屏自动堆叠

## 备案

```js
beian: {
  enable: true,
  icp: [
    { text: "京ICP备00000000号", url: "https://beian.miit.gov.cn" }
  ],
  position: "bottom"
}
```

| 字段 | 说明 |
| --- | --- |
| `enable` | 是否显示备案行 |
| `icp` | 1–3 条记录，`url` 可选 |
| `position` | `"top"` 紧跟版权上方；`"bottom"` 在页脚最底部 |

## 隐藏整个页脚

```js
layout: { show_footer: false }
```

## 自定义页脚 HTML

```js
layout: { footer_file: "/footer.html" }
```

读取内容分支中的 `/footer.html`，消毒后注入。一般不需要：内置页脚已经能通过 `footer.*` 完整配置。
