# 配置详解

`config.js` 是站点的唯一配置入口，位于内容分支根目录。

## 加载方式

```text
easydocument.json（main 分支）
{ "data": "data:/config.js" }
        │       │
        │       └── config.js 在内容分支中的路径
        └────────── 内容所在分支
```

- 文档根 = `config.js` 所在目录
- 因此也可以写成 `content:docs/config.js`，把内容放进子目录
- 变更 `config.js` 本身也要走「提交 + 重建」才生效

## 所有字段都可选

未填写的字段使用内置默认值；类型不符会回退默认值并给出提示。

在编辑台的「站点配置」里可以看到校验结果，在源码视图里保存前也会先校验。

## 最小可用配置

```js
const config = {
  site: {
    name: "我的文档",
    title: "我的文档",
    description: "用 EasyDocument 搭建",
    base_url: "/"
  }
};

export default config;
```

其余一切都会走默认值：单版本、README 作为索引页、搜索开启、暗色模式跟随系统。

## 修改配置的两种方式

### 网页端（推荐）

1. `/admin` → **站点配置**
2. 表单视图改常用项，或切到源码视图改全文
3. 点 **提交配置**
4. 到 **构建部署** 触发重建

### 本地

```bash
# 在内容分支工作区直接改
$EDITOR .data/config.js
git -C .data add config.js && git -C .data commit -m "config: ..." && git -C .data push
```

## 常见配置错误

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 导航项灰色不可点 | 配的路径没有对应文档 | 补文档，或改路径 |
| 版本没出现 | 目录不存在 / 不在 `available_branches` | 建目录，或加进列表 |
| 目录不可点 | 目录里没有索引页 | 放一个 `README.md` |
| 主题色没生效 | 值不是合法颜色 | 用 `#rrggbb` |
| 首页搜索框不见了 | `home.hero.search_placeholder` 为空 | 填一个占位文案 |
