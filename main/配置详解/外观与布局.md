# 外观与布局

## 外观

```js
appearance: {
  logo: "/assets/img/logo.svg",
  favicon: "/assets/img/favicon.ico",
  theme_color: "#3b82f6",
  default_dark_mode: "auto",
  font_family: ""
}
```

| 字段 | 说明 |
| --- | --- |
| `logo` | 顶栏与首页 Logo；相对路径按 `base_url` 解析 |
| `favicon` | 站点图标，写入 `<link rel="icon">` |
| `theme_color` | 生成 `--ed-primary` 等主题变量 |
| `default_dark_mode` | `"auto"` 跟随系统 / `"light"` / `"dark"` |
| `font_family` | 留空用内置 Outfit；非空覆盖字体族 |

## 布局

```js
layout: {
  show_header: true,
  header_file: "",
  show_footer: true,
  footer_file: "",
  sidebar_width: "260px",
  toc_width: "260px",
  mobile_breakpoint: "1024px"
}
```

| 字段 | 说明 |
| --- | --- |
| `show_header` / `show_footer` | 是否显示内置顶栏 / 页脚 |
| `header_file` / `footer_file` | 自定义 HTML 文件路径；**仅在设置了内置渲染之外的场景使用**，内容会经消毒后注入 |
| `sidebar_width` | 左侧文档树宽度（CSS 长度） |
| `toc_width` | 右侧目录宽度 |
| `mobile_breakpoint` | 移动端抽屉断点（CSS 长度） |

> [NOTE] 默认使用内置的 React 顶栏与页脚，由 `navigation.nav_links` 与 `footer.*` 驱动。只有在需要完全自定义的 HTML 时才使用 `header_file` / `footer_file`。

## 导航

```js
navigation: {
  home_text: "首页",
  breadcrumb: true,
  auto_collapse: true,
  back_to_top: true,
  prev_next_buttons: true,
  folder_expand_mode: 5,
  nav_links: [ ... ]
}
```

### folder_expand_mode

侧栏初始展开方式：

| 值 | 行为 |
| --- | --- |
| 1 | 展开全部第一级目录 |
| 2 | 展开全部目录 |
| 3 | 展开第一个目录的第一级 |
| 4 | 展开第一个目录的全部子目录 |
| 5 | 不展开（默认） |

无论取值如何，当前文档所在的目录链都会被展开。

### nav_links

```js
nav_links: [
  { text: "首页", url: "/" },
  { text: "文档", url: "/docs/main" },
  {
    text: "教程",
    url: [
      { text: "快速入门", url: "/docs/main/快速入门", icon: "fas fa-rocket" }
    ],
    icon: "fas fa-graduation-cap"
  },
  { text: "GitHub", url: "https://github.com/…", external: true }
]
```

| 字段 | 说明 |
| --- | --- |
| `text` | 显示文本 |
| `url` | 字符串或数组（数组渲染为下拉） |
| `icon` | FontAwesome 类名；内置常用图标的兼容映射 |
| `external` | 外部链接，自动加 `target="_blank"` |

**站内路径会校验存在性**：目标不存在时该项显示为灰色且不可点击，不会跳到 404。

## 动画

```js
animation: {
  enable: true,
  sidebar: { enable: true, duration: 200, stagger_delay: 50, enable_skeleton: true, skeleton_duration: 1500 },
  toc:     { enable: true, duration: 200, stagger_delay: 50, enable_skeleton: true, skeleton_duration: 1500 },
  article: { enable_skeleton: true, enable_render: true, render_duration: 600 },
  general: { min_duration: 300 }
}
```

| 字段 | 说明 |
| --- | --- |
| `enable` | 总开关；false 时所有动画缩短到 1ms |
| `sidebar` / `toc` | 列表交错入场、骨架屏 |
| `article` | 正文骨架屏与淡入 |
| `general.min_duration` | 加载态最短展示时长 |

系统设置了 `prefers-reduced-motion: reduce` 时，动画会自动降级。

## 典型调整

**加宽侧栏与目录**

```js
layout: { sidebar_width: "300px", toc_width: "240px" }
```

**固定暗色**

```js
appearance: { default_dark_mode: "dark" }
```

**全部展开侧栏**

```js
navigation: { folder_expand_mode: 2 }
```
