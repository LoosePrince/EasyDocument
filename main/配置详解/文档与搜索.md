# 文档与搜索

## document

### 版本

```js
document: {
  root_dir: "/",
  branch_support: true,
  default_branch: "main",
  available_branches: [{ name: "main", label: "v2.0.2" }],
  default_page: "README.md"
}
```

| 字段 | 说明 |
| --- | --- |
| `root_dir` | 内容根（相对配置所在目录）；一般保持 `"/"` |
| `branch_support` | 是否按一级目录区分版本 |
| `default_branch` | 默认版本目录名 |
| `available_branches` | 展示顺序与标签；目录不存在时自动隐藏 |
| `default_page` | 目录无索引页时的回退文件名 |

### 索引页

```js
index_pages: ["README.md", "README.html", "index.md", "index.html"]
```

按数组顺序取第一个存在的作为目录索引页。**只有存在索引页的目录，侧栏才给可点击入口。**

### 文件类型

```js
supported_extensions: [".md", ".html"]
```

不在列表中的扩展名不会出现在侧栏、搜索与构建产物里。

### 目录（TOC）

```js
toc_depth: 3,
toc_numbering: true,
toc_ignore_h1: true,
toc_dynamic_expand: true
```

| 字段 | 说明 |
| --- | --- |
| `toc_depth` | 右侧目录显示到几级标题 |
| `toc_numbering` | 是否显示 `1 / 1.2 / 1.2.3` 编号 |
| `toc_ignore_h1` | 编号时不计入 h1，避免全部以 1 开头 |
| `toc_dynamic_expand` | 超出深度的标题在激活其上级时展开 |

### 代码块

```js
code_copy_button: true,
code_block: {
  line_numbers: true,
  start_line: 1,
  theme: { light: "github", dark: "github-dark" }
}
```

- `start_line` 影响行号起点与 `data-line` 属性
- 主题名使用 shiki 内置名称；`github` 会归一为 `github-light`

### 目录配置（path.json）

```js
path_config: "path.json", // 目录配置文件名，放在内容根或版本目录下
runtime_fetch: true       // 允许前端实时拉取外部文档
```

`path.json` 负责**显示名、排序、隐藏、外部挂载**，不改变物理文件名：

```json
{
  "children": [
    { "path": "README.md", "title": "概览", "icon": "home" },
    { "path": "使用指南", "title": "使用手册", "icon": "book" },
    { "path": "旧版", "hidden": true },
    {
      "path": "外部文档",
      "icon": "https://example.com/icons/external.svg",
      "external": {
        "mode": "github_tree",
        "url": "https://github.com/owner/repo/tree/main/docs"
      }
    }
  ]
}
```

`icon` 可以是图标库 id（见[图标一览](../参考/图标一览.md)）或图标链接；目录与文档都支持。
在控制台「目录与排序」里点每行的图标按钮，会打开图标库弹窗。

| `external.mode` | url 填什么 |
| --- | --- |
| `path_json` | 远端 `path.json` 的完整链接，或包含 `path.json` 的公开目录 |
| `github_tree` | GitHub 目录链接，如 `https://github.com/owner/repo/tree/main/docs` |

- 两种方式都**不需要 token**（GitHub 走公开 Contents API）
- 构建期拉取一次并参与预渲染；`runtime_fetch: true` 时前端也会实时刷新
- 构建期成功拉取的正文会进入**搜索索引**，因此外部文档一样可以被搜索到
- 某个挂载失败只会在构建日志里给出 warning，不会中断整体构建

> [NOTE] 外部挂载写在 `path.json` 里（v2.0.1 起），原先的 `document.external_docs` 已移除。

## i18n（v2.0.2）

站点语言与文档语言分开配置：站点语言只影响界面文案，保存在浏览器 `localStorage`；文档语言决定内容，并出现在 `/docs-{文档语言}/` 路径前缀中。

```js
i18n: {
  enable: true,              // 总开关
  ui: true,                  // 翻译界面文案（内置中文 / English，英文文案在 lang/en.json）
  switcher: true,            // 顶栏语言切换器（站点语言 + 文档语言两个列表）
  default_language: "zh-CN", // 默认站点语言（中文）
  site_languages: [
    { code: "zh-CN", label: "中文" },
    { code: "en", label: "English" }
  ],
  // 文档语言可以自由扩展，甚至只保留一个（此时不显示文档语言列表）
  document_languages: [
    { code: "zh-CN", label: "中文", dir: "zh", suffix: "zh" },
    { code: "en", label: "English", dir: "en", suffix: "en" }
  ],
  default_document_language: "zh-CN",
  // auto：同时识别文件夹与后缀；folder / suffix / off 可强制单一方式
  document_mode: "auto"
}
```

| 字段 | 说明 |
| --- | --- |
| `enable` | 关闭后不识别多语言文档，也不显示切换器 |
| `ui` | 是否翻译界面文案 |
| `switcher` | 顶栏语言切换按钮；点开后分别列出站点语言与文档语言 |
| `default_language` | 默认站点语言，只影响界面文案 |
| `site_languages[].code` | 站点语言代码，仅用于界面与 `localStorage`，不出现在 URL |
| `document_languages[].code` | 文档语言代码 |
| `document_languages[].dir` | 语言文件夹名（`document_mode` 为 folder / auto） |
| `document_languages[].suffix` | 文件二级后缀（`document_mode` 为 suffix / auto） |
| `default_document_language` | 默认文档语言；站点语言没有对应文档时回落到它 |
| `document_mode` | `auto` / `folder` / `suffix` / `off` |

两种文档组织方式：

```text
# 方式一：语言文件夹
main/
├── zh/使用指南/README.md   → /docs-zh-CN/main/使用指南
└── en/使用指南/README.md   → /docs-en/main/使用指南

# 方式二：文件二级后缀
main/使用指南/
├── README.zh.md           → /docs-zh-CN/main/使用指南
└── README.en.md           → /docs-en/main/使用指南
```

- 没有语言标记的文件属于默认语言
- 同一逻辑路径优先使用显式语言标记
- 某语言没有对应译文时，会自动显示默认语言内容，并在页面上给出提示
- **站点语言切换时，文档语言自动跟随**；也可以单独选择文档语言（不会反向修改站点语言）
- 站点语言只保存在浏览器 `localStorage`，不出现在 URL 中
- 文档语言始终位于 URL 前缀：`/docs-en/main/使用指南`
- 旧地址 `/docs/main/...` 仍可用，会自动跳转到 `/docs-{默认文档语言}/main/...`

### 站点配置多语言（locales）

`config.js` 顶层的 `locales` 按站点语言覆盖基础配置，适合提供英文版导航、首页与页脚：

```js
const config = {
  site: { title: "EasyDocument · 静态文档系统" },
  navigation: { nav_links: [/* 中文导航 */] },
  home: { /* 中文首页 */ },

  locales: {
    en: {
      site: {
        title: "EasyDocument · Static Documentation",
        description: "Documentation separated from code"
      },
      navigation: {
        home_text: "Home",
        nav_links: [
          { text: "Home", url: "/" },
          { text: "Docs", url: "/docs-en/main" }
        ]
      },
      home: {
        hero: {
          subtitle: "Documentation separated from code",
          button_text: "Start reading",
          button_link: "/docs-en/main"
        }
      },
      search: { placeholder: "Search docs…" },
      footer: {
        links: [{ text: "Report an issue", url: "https://github.com/…" }]
      }
    }
  }
};
```

- 对象字段深合并；数组（`nav_links`、`home.features`、`home.quick_links`、`footer.links` 等）整体替换
- 未在 `locales[语言]` 中出现的字段沿用基础配置
- 站点语言只保存在 `localStorage`，切换后前端即时使用对应 `locales` 配置，不改变 URL

## search

```js
search: {
  enable: true,
  min_chars: 2,
  max_results: 20,
  placeholder: "搜索文档…",
  search_drafts: true,
  search_on_type: true,
  match_distance: 50
}
```

| 字段 | 说明 |
| --- | --- |
| `enable` | 关闭后顶栏与首屏搜索框都隐藏 |
| `min_chars` | 触发搜索的最小字符数 |
| `max_results` | 最多返回条数 |
| `search_drafts` | 是否同时搜索浏览器内的本地草稿 |
| `search_on_type` | 输入即搜；false 时需回车 |
| `match_distance` | 结果片段中多次命中的最小间隔 |

搜索索引在构建期生成到 `search-index.<版本>.json`，因此**新增文档后需要重新构建**才可被搜索到。

## extensions

```js
extensions: {
  math: true,
  highlight: true,
  mermaid: true,
  html_scripts: true,
  github: {
    enable: true,
    repo_url: "https://github.com/owner/repo",
    edit_link: true,
    branch: "main",
    show_avatar: true
  },
  git: {
    enable: true,
    show_last_modified: true,
    show_contributors: true
  },
  progress_bar: { enable: true }
}
```

| 字段 | 说明 |
| --- | --- |
| `math` | KaTeX 数学公式 |
| `highlight` | shiki 代码高亮（双主题） |
| `mermaid` | Mermaid 图表渲染 |
| `html_scripts` | HTML 文档是否执行脚本（默认 `true`，不再做安全限制） |
| `github.enable` | GitHub 相关功能总开关 |
| `github.repo_url` | 仓库地址；省略时按 CI 变量 / Pages 域名 / git remote 推断 |
| `github.edit_link` | 文档底部「在 GitHub 上编辑」 |
| `github.branch` | 编辑链接指向的代码分支 |
| `github.show_avatar` | 贡献者显示头像而不是首字母 |
| `git.show_last_modified` | 显示最后编辑时间 |
| `git.show_contributors` | 显示贡献者 |
| `progress_bar.enable` | 顶部阅读进度条 |

> [NOTE] `git` 信息由构建期读取内容工作区的 `git log` 生成（最后修改时间与贡献者）。本地构建若没有 `.data` 副本，可能拿不到，此时这些信息会自动隐藏。v2.0.2 修复了该信息未渲染的问题。

## admin

```js
admin: { enable: true }
```

| 值 | 效果 |
| --- | --- |
| `true` | 文档页显示「编辑此页」「新建 / 管理」，`/admin` 可用 |
| `false` | 隐藏所有编辑入口，`/admin` 显示关闭提示 |

> [WARNING] 这不是权限控制：关闭只是隐藏入口，仓库的写入权限仍由 GitHub Token 决定。
